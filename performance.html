1. Carga del archivo de ventas

Formatos admitidos: .xlsx, .xls, .csv. El sistema lee la columna DescrSubCategoría (columna J) y detecta automáticamente cliente, kilos y venta.

Arrastre aquí el archivo o selecciónelo

La información se procesa 100% en su navegador. Ningún dato se envía a internet.

2. Mapeo de columnas

Verifique que las columnas detectadas sean las correctas antes de procesar.

3. Cuotas y metas del mes

TARGET ACT = cuota de cumplimiento de activación exigida por Nestlé. La cuota en kilos se carga por chat / negociación mensual. Las categorías marcadas como FOCO son las del reporte detallado.

CategoríaTarget Act %Cuota Kg mesFoco

4. Publicar la actualización en GitHub

El panel visual siempre muestra los datos del archivo datos.js. Al reemplazarlo en el repositorio, el tablero publicado queda actualizado para todos.

  1. Procese el archivo del mes en este panel.
  2. Presione Generar datos.js y guarde el archivo.
  3. En GitHub, abra el repositorio y use Add file → Upload files.
  4. Suba datos.js en la raíz, junto a index.html, y confirme con Commit changes.
  5. En 1 o 2 minutos el enlace de GitHub Pages muestra la información nueva.
Importante
El archivo datos.js se sobrescribe cada mes con el mismo nombre; GitHub conserva el historial de versiones.

Mientras no se suba el archivo, cada equipo ve la última carga guardada en su propio navegador.
Aún no hay información cargada La información se publica desde admin.html. Suba el archivo datos.js al repositorio para ver el reporte del mes.
